# `ytdown` PRD

## 개요

YouTube URL을 입력하면 영상 또는 음성을 내려받는 경량 데스크톱 앱이다. 배포 편의성을 최우선으로 한다.

- 목적: 영상(원본 화질)과 음성을 각각 간편하게 다운로드
- 대상: 일반 사용자 (패키징된 설치 파일로 배포)
- 핵심 경험: 전역 단축키로 창 호출 → URL 입력 → Enter → 백그라운드 다운로드

## 기술 스택 및 지원 플랫폼

Tauri v2를 사용한다. 공식 번들러와 CI 액션으로 3개 OS 설치 파일을 일괄 생성할 수 있기 때문이다.

| 구분 | 선택 |
| --- | --- |
| 프레임워크 | Tauri v2 |
| 프론트엔드 | 순수 HTML/CSS/JS (프레임워크 없음) |
| Tauri 플러그인 | global-shortcut, dialog, store (프로세스 실행·HTTP는 Rust 표준 크레이트로 처리) |
| 다운로드 엔진 | yt-dlp 실행 파일 (하위 프로세스 호출) |
| 로직 구현 위치 | Rust 커맨드 (의존성 관리, 프로세스 제어, 진행률 파싱). JS는 UI 전담 |
| 미디어 처리 | ffmpeg 실행 파일 |
| 빌드 | GitHub Actions (tauri-action) |

| 플랫폼 | 지원 수준 |
| --- | --- |
| macOS | 필수 |
| Windows | 필수 |
| Ubuntu | 가능한 범위 (X11 우선, WebKitGTK 의존). 전역 단축키는 X11 한정, Wayland에서는 미지원 (등록 실패 시 설정 화면에 안내만 표시) |

## 기능 요구사항

### 실행 형태

- 일반 창 앱 (트레이 상주 없음)
- 앱 실행 중이면 다른 앱 사용 중에도 전역 단축키로 창 활성화 및 URL 입력창 포커스
- 단축키 기본값 Ctrl+Option+Y (macOS) / Ctrl+Alt+Y (Windows·Ubuntu), 설정에서 변경 가능

### 메인 화면

- 영상 URL 입력창, 음성 URL 입력창을 별도로 배치
- Enter 시 즉시 다운로드 시작, 입력창은 비워 다음 입력 대기
- 다운로드 목록: 항목별 제목, 유형(영상/음성), 진행률, 취소 버튼

### 다운로드

- 동시 다운로드 기본 상한 3개 (항목별 독립 yt-dlp 프로세스), 초과분은 대기열에서 대기 (HTTP 429 회피)
- 영상: 설정의 기본 화질과 컨테이너(MP4/MKV/WebM/원본)로 저장
- 음성: 설정의 포맷(MP3/M4A/Opus 등 또는 원본, 원본은 재인코딩 없음)으로 추출
- 재생목록 URL: Enter 시 판별되면 모달로 단일 영상/전체/취소 선택 (일반 URL은 즉시 시작)
- 취소 시 프로세스 종료 및 임시 파일 정리

### 외부 의존성 관리

- 대상: yt-dlp, ffmpeg (yt-dlp가 요구할 경우 JS 런타임 포함)
- 저장 위치: 앱 데이터 폴더 (설치 파일에 동봉하지 않음)
- 최초 실행: 다운로드, 체크섬 검증, 실행 권한 부여(macOS/Linux), macOS는 격리 속성(com.apple.quarantine) 제거
- 매 실행: yt-dlp 최신 버전 확인 후 업데이트, ffmpeg는 누락·손상 시에만 재다운로드
- 오프라인 등으로 업데이트 확인 실패 시: 경고만 표시하고 기존 바이너리로 진행 (최초 실행이면 오류 + 재시도)
- 준비 완료 전에는 다운로드 입력 비활성화, 진행 상태 표시
- 실패 시 오류 안내 및 재시도 버튼

### 설정

- 저장 위치: Tauri appConfigDir (경로 명시 지정)

| 항목 | 기본값 |
| --- | --- |
| 다운로드 폴더 | OS 다운로드 폴더 |
| 기본 화질 | 최고 화질 |
| 영상 컨테이너 | 원본 |
| 음성 포맷 (음성 전용 다운로드) | 원본 |
| 영상 코덱 우선순위 | 자동 |
| 음질 (음성 전용 다운로드) | 최고 |
| 영상 음성 코덱 | 자동 |
| 영상 음성 최대 비트레이트 | 최고 |
| 영상 음성 재인코딩 | 끔 |
| 전역 단축키 | Ctrl+Option+Y (macOS) / Ctrl+Alt+Y |
| 의존성 수동 업데이트 | 버튼 |

## 비기능 요구사항 및 배포

- 경량: 설치 파일에 yt-dlp/ffmpeg 미포함
- 배포 형식: macOS dmg, Windows msi 또는 exe, Ubuntu deb/AppImage
- 서명: macOS 공증, Windows 코드 서명
- 권한 안내: macOS 손쉬운 사용 권한 (전역 단축키)
- 앱 자체 업데이트 기능 없음 (새 버전은 수동 설치)

## 범위 제외

- 트레이 상주, 로그인 시 자동 실행
- 로그인 필요 영상 (연령 제한, 멤버십, 브라우저 쿠키 연동)
- 앱 자체 자동 업데이트
- Ubuntu Wayland 전역 단축키

## 검증 필요 사항

- [x] macOS(특히 Apple Silicon)용 ffmpeg 신뢰 가능한 배포처 확정: macOS는 osxexperts.net (URL·해시 고정), Windows/Linux는 BtbN/FFmpeg-Builds (GPL 정적 빌드)
- [ ] 앱이 내려받은 실행 파일에 macOS 격리 속성이 붙어 실행이 차단되는지 확인 (xattr 제거 동작 포함 실기 검증)
- [ ] yt-dlp의 JS 런타임(Deno 등) 요구 여부를 최신 릴리스 노트로 확인
- [ ] store 플러그인 저장 경로를 appConfigDir로 지정 시 OS별 실제 경로 확인
- [ ] 동시 다운로드 상한 3에서 YouTube 속도 제한(HTTP 429) 발생 여부 및 상한 적정성
- [ ] ffmpeg 라이선스(LGPL/GPL) 및 YouTube 약관 관련 고지 문구 검토
