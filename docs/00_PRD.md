# `ytdown` PRD

## 개요

YouTube URL을 입력하면 영상 또는 음성을 내려받는 경량 데스크톱 앱이다. 배포 편의성을 최우선으로 한다.

- 목적: 영상(원본 화질)과 음성을 각각 간편하게 다운로드
- 대상: 일반 사용자 (패키징된 설치 파일로 배포)
- 핵심 경험: 전역 단축키로 창 호출 → URL 입력 → Enter → 백그라운드 다운로드

## 기술 스택 및 지원 플랫폼

Tauri v2를 사용한다. 공식 번들러와 CI 액션으로 3개 OS 설치 파일을 일괄 생성할 수 있기 때문이다.

| 구분 | 선택 |
| --- | --- |
| 프레임워크 | Tauri v2 |
| 프론트엔드 | 순수 HTML/CSS/JS (프레임워크 없음) |
| Tauri 플러그인 | global-shortcut, dialog (설정은 appConfigDir의 settings.json, 프로세스 실행·HTTP는 Rust 크레이트로 처리) |
| 다운로드 엔진 | yt-dlp 실행 파일 (하위 프로세스 호출) |
| 로직 구현 위치 | Rust 커맨드 (의존성 관리, 프로세스 제어, 진행률 파싱). JS는 UI 전담 |
| 미디어 처리 | ffmpeg 실행 파일 |
| 빌드 | GitHub Actions (tauri-action) |

| 플랫폼 | 지원 수준 |
| --- | --- |
| macOS | 필수 |
| Windows | 필수 |
| Ubuntu | 가능한 범위 (X11 우선, WebKitGTK 의존). 전역 단축키는 X11 한정, Wayland에서는 미지원 (등록 실패 시 설정 화면에 안내만 표시) |

## 기능 요구사항

### 실행 형태

- 일반 창 앱 (트레이 상주 없음), 창 제목 "ytdown by Patrick Yu", 420×420 고정 크기(크기 변경 불가), 헤더 로고는 앱 아이콘
- 오른쪽 클릭 메뉴는 URL 입력창에서만 표시
- 앱 실행 중이면 다른 앱 사용 중에도 전역 단축키로 창 활성화 및 URL 입력창 포커스
- 단축키 기본값 Ctrl+Option+Y (macOS) / Ctrl+Alt+Y (Windows·Ubuntu), 설정에서 키를 눌러 녹화하는 방식으로 변경 (⌘/Ctrl 하나 + 키, ⌘/Ctrl+Space 등 시스템 표준 조합은 거부)
- URL 입력창 포커스: 앱 시작(입력 가능해지는 시점), 전역 단축키, 창 활성화 시. 대화상자가 열려 있으면 제외

### 메인 화면

- URL 입력창 하나와 "Audio only" 스위치. 스위치를 켜면 음성만 다운로드
- Enter 시 즉시 다운로드 시작, 입력창은 비워 다음 입력 대기. Shift+Enter는 스위치와 무관하게 이번 한 번만 음성
- 다운로드 목록: 항목별 제목, 유형(영상/음성), 진행률, 취소(×) 버튼
  - 진행 중: 스트림 단계와 퍼센트 표시 (예: "Video · Audio 2/2 · 87%")
  - 완료: 진행률 막대 숨김, 제목 흐리게, 용량 표시 (예: "Video · 12.3 MB")
  - 재생목록 전체: 재생목록 행(제목 = 재생목록 이름, "Playlist · 완료/전체 · %") 아래에 실제 받는 항목이 시작 순서대로 하위 행으로 추가됨. 실패한 항목은 실패로 표시하고 나머지는 계속 받음. 완료 시 "Playlist · N items · 용량", 일부 실패면 "n of N failed" 안내
  - 취소는 재생목록 단위(재생목록 행의 ×)만 가능, 항목별 취소 없음
  - 목록만 스크롤 (헤더와 입력창은 고정), "Clear finished"로 종료된 항목 정리
- 키보드: ⌘⇧A / Ctrl+Shift+A로 Audio only 토글, Ctrl+, (macOS는 ⌘,도)로 설정 열기, 설정 안에서 ⌘S / Ctrl+S 저장, Esc 닫기

### 다운로드

- 동시 다운로드 기본 상한 3개 (항목별 독립 yt-dlp 프로세스), 초과분은 대기열에서 대기 (HTTP 429 회피)
- 영상: 설정의 최대 해상도, 컨테이너(원본/MP4/MKV/WebM), 영상 코덱 우선순위로 저장
  - 영상 속 음성 트랙: 코덱 선호(자동/AAC/Opus), 최대 비트레이트로 원본 스트림을 고르고, 필요하면 병합 시 음성만 재인코딩(AAC/MP3/Opus, MP4·MKV 컨테이너만)
- 음성 전용: 설정의 포맷(원본/MP3/M4A/Opus/FLAC/WAV, 원본은 재인코딩 없음)과 음질로 추출
- 재생목록 URL: Enter 시 판별되면 모달로 단일 영상/전체/취소 선택 (일반 URL은 즉시 시작). 영상 없는 재생목록 URL(`/playlist?list=`)은 "전체/취소"만 선택
- 취소 시 프로세스 종료 및 임시 파일 정리

### 외부 의존성 관리

- 대상: yt-dlp(onedir 빌드, `bin/yt-dlp/` 폴더), ffmpeg, Deno(yt-dlp의 YouTube 추출에 필요한 JS 런타임)
- 저장 위치: 앱 데이터 폴더의 `bin/` (설치 파일에 동봉하지 않음)
- 설치: 다운로드, sha256 검증, 실행 권한 부여(macOS/Linux), macOS는 격리 속성 제거, 원자적 교체
- 앱 시작: 파일 존재 여부만 확인 → 누락 시 즉시 설치(그동안만 입력 비활성화), 그 외에는 바로 입력 가능
- 업데이트: 시작 후 백그라운드에서 yt-dlp 최신 버전 확인 → 새 버전은 `bin/pending/`에 받아 두고 다음 실행 시 적용. 확인 실패 시 경고만 표시
- 설정의 Update 버튼: 즉시 확인·적용 (Windows에서 실행 중이라 교체가 막히면 다음 실행 시 적용)
- 다운로드 시작 시: ffmpeg/Deno는 빠른 동작 점검, yt-dlp는 실제 실행 결과로 판단. 고장이면 재설치 후 계속(yt-dlp는 1회 재시도)
- 실패 시 오류 안내 및 재시도 버튼

### 설정

- 저장 위치: Tauri appConfigDir (경로 명시 지정)

## 비기능 요구사항 및 배포

- 경량: 설치 파일에 yt-dlp/ffmpeg 미포함
- UI 글꼴: Inter(SIL OFL, 352KB)를 앱에 포함해 OS와 관계없이 동일하게 표시 (한글 등은 시스템 글꼴)
- 접근성: 텍스트 대비 WCAG AA(4.5:1) 이상, 키보드 포커스 표시
- 배포 형식: macOS Apple Silicon dmg, Windows NSIS setup(.exe), Ubuntu x86_64 deb (CI 릴리스 산출물은 이 3개로 제한)
- 서명: macOS 공증, Windows 코드 서명
- 권한 안내: macOS 손쉬운 사용 권한 (전역 단축키)
- 앱 자체 업데이트 기능 없음 (새 버전은 수동 설치)

## 범위 제외

- 트레이 상주, 로그인 시 자동 실행
- 로그인 필요 영상 (연령 제한, 멤버십, 브라우저 쿠키 연동)
- 앱 자체 자동 업데이트
- Ubuntu Wayland 전역 단축키
