# ytdown Implementation Plan

> **Historical:** initial v1 plan (Tasks 0–9). Later changes (Tasks 10–20, UI polish) and every deviation are recorded in `docs/02_decisions.md`; current behaviour is in `docs/00_PRD.md`.

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** YouTube URL을 입력하면 영상/음성을 내려받는 Tauri v2 데스크톱 앱 (macOS/Windows 필수, Ubuntu 가능 범위).

**Architecture:** 로직은 전부 Rust 커맨드(의존성 관리, yt-dlp 프로세스, 대기열, 설정). 프론트는 프레임워크 없는 HTML/CSS/JS이며 `window.__TAURI__` 전역으로 invoke/listen만 수행. 진행 상태는 Tauri 이벤트로 푸시.

**Tech Stack:** Tauri v2, Rust (tokio, reqwest[rustls], sha2, serde, url, tokio-util, zip), 플러그인 global-shortcut / dialog, yt-dlp, ffmpeg, GitHub Actions (tauri-action).

**Spec:** `docs/00_PRD.md`

## Global Constraints

- 로직은 Rust 커맨드에서 구현, JS는 UI 전담 (shell/http 플러그인 사용 안 함)
- 동시 다운로드 기본 상한 3, 초과분은 대기열
- yt-dlp/ffmpeg는 설치 파일에 동봉하지 않고 앱 데이터 폴더에 저장
- 최초 실행: 다운로드 + 체크섬 검증 + 실행 권한(macOS/Linux) + macOS 격리 속성(`com.apple.quarantine`) 제거
- 업데이트 확인 실패(오프라인 등) 시 경고만 표시하고 기존 바이너리로 진행 (최초 실행이면 오류 + 재시도)
- 전역 단축키 기본값 `CommandOrControl+Shift+Y`, 설정에서 변경 가능. Ubuntu Wayland 미지원(X11 한정)
- 재생목록 URL은 모달로 단일/전체/취소 선택, 일반 URL은 즉시 시작
- 설정 기본값: 다운로드 폴더=OS 다운로드 폴더, 화질=최고, 컨테이너=MP4, 음성=MP3
- 취소 시 프로세스 종료 및 임시 파일 정리
- 앱 자체 업데이트, 트레이, 자동 실행, 로그인 필요 영상 제외
- 코드 주석/출력 메시지는 영어

  ```rust
  use url::Url;

  #[derive(Debug, PartialEq, Clone, Copy)]
  pub enum UrlKind { Video, Playlist, Invalid }

  pub fn classify(input: &str) -> UrlKind {
      let Ok(u) = Url::parse(input.trim()) else { return UrlKind::Invalid };
      if u.scheme() != "https" && u.scheme() != "http" { return UrlKind::Invalid }
      let host = u.host_str().unwrap_or("").trim_start_matches("www.").trim_start_matches("m.");
      if host != "youtube.com" && host != "youtu.be" && host != "music.youtube.com" {
          return UrlKind::Invalid;
      }
      if u.query_pairs().any(|(k, _)| k == "list") { UrlKind::Playlist } else { UrlKind::Video }
  }
  ```

  ```rust
  use serde::{Deserialize, Serialize};
  use std::path::PathBuf;
  use tauri::{AppHandle, Manager};

  #[derive(Serialize, Deserialize, Clone)]
  pub struct Settings {
      pub download_dir: PathBuf,
      pub quality: Option<u32>, // None = best
      pub container: String,    // mp4 | mkv | webm
      pub audio_format: String, // mp3 | m4a | opus | ...
      pub shortcut: String,
  }

  impl Settings {
      pub fn new(download_dir: PathBuf) -> Self {
          Self { download_dir, quality: None, container: "mp4".into(),
                 audio_format: "mp3".into(), shortcut: "CommandOrControl+Shift+Y".into() }
      }
  }

  fn path(app: &AppHandle) -> PathBuf {
      app.path().app_config_dir().expect("config dir").join("settings.json")
  }

  pub fn load(app: &AppHandle) -> Settings {
      std::fs::read(path(app)).ok()
          .and_then(|b| serde_json::from_slice(&b).ok())
          .unwrap_or_else(|| Settings::new(app.path().download_dir().unwrap_or_default()))
  }

  pub fn save(app: &AppHandle, s: &Settings) -> Result<(), String> {
      let p = path(app);
      std::fs::create_dir_all(p.parent().unwrap()).map_err(|e| e.to_string())?;
      std::fs::write(p, serde_json::to_vec_pretty(s).unwrap()).map_err(|e| e.to_string())
  }
  ```

  ```rust
  use crate::settings::Settings;
  use serde::{Deserialize, Serialize};
  use std::path::Path;

  #[derive(Serialize, Deserialize, Clone, Copy, PartialEq, Debug)]
  #[serde(rename_all = "lowercase")]
  pub enum Kind { Video, Audio }

  pub fn build(kind: Kind, url: &str, playlist: bool, s: &Settings, ffmpeg: &Path, tmp: &Path) -> Vec<String> {
      let mut a: Vec<String> = vec![
          "--newline".into(), "--no-colors".into(),
          "--progress-template".into(), "download:ytdown:%(progress._percent_str)s".into(),
          "--print".into(), "before_dl:ytdown-title:%(title)s".into(), "--no-simulate".into(),
          "--ffmpeg-location".into(), ffmpeg.display().to_string(),
          "-P".into(), format!("temp:{}", tmp.display()),
          "-P".into(), s.download_dir.display().to_string(),
          "-o".into(), "%(title)s.%(ext)s".into(),
          (if playlist { "--yes-playlist" } else { "--no-playlist" }).into(),
      ];
      match kind {
          Kind::Video => {
              let f = match s.quality {
                  None => "bv*+ba/b".to_string(),
                  Some(h) => format!("bv*[height<={h}]+ba/b[height<={h}]"),
              };
              a.extend(["-f".into(), f, "--merge-output-format".into(), s.container.clone()]);
          }
          Kind::Audio => a.extend(["-x".into(), "--audio-format".into(), s.audio_format.clone()]),
      }
      // "--" stops option parsing so a URL can never be read as a flag
      a.extend(["--".into(), url.into()]);
      a
  }
  ```

  2. id 발급, `CancellationToken` 등록, `tauri::async_runtime::spawn(run_job(...))`, id 반환.

  `run_job` 흐름:
  1. `queued` 이벤트 → `tokio::select!{ p = sem.acquire_owned() => p, _ = tok.cancelled() => { emit canceled; return } }`.
  2. `tmp = app_cache_dir/ytdown-<id>`; `Command::new(ytdlp_path).args(args::build(...)).stdout(piped).stderr(piped).kill_on_drop(true).spawn()`.
  3. stdout를 `BufReader::lines()`로 읽으며 `progress::parse` → `Title`/`Percent`를 `running` 이벤트로 발행. stderr는 마지막 몇 줄을 버퍼링해 오류 메시지로 사용.
  4. `select!{ status = child.wait() => ..., _ = tok.cancelled() => { child.kill().await; emit canceled } }`.
  5. 종료 시 항상 `remove_dir_all(tmp)`; 성공은 `done`, 실패는 `error` + stderr 마지막 줄(`HTTP Error 429` 포함 시 "Rate limited by YouTube. Retry later." 로 치환).
  6. jobs 맵에서 id 제거.
